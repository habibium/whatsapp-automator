# AGENTS.md

Guidance for AI coding agents working in this repository. The web app (Vite + React + TanStack)
lives in `web/`; the Rust API server lives in `server/`. Everything below concerns `web/`, and every
command listed here runs from that directory.

## Project conventions

These override the CLI-managed Astryx block below wherever they disagree.

- StyleX only. No Tailwind, no `className` utilities, no CSS modules, no `style={{}}`.
- Custom styling = `stylex.create` passed to a component's `xstyle` prop. `stylex.props` only on the
  rare DOM node Astryx has no component for; reach for a layout component (VStack/HStack/Center/
  Section/Layout) before any raw `<div>`.
- Values come from `@astryxdesign/core/theme/tokens.stylex` (e.g. `colorVars['--color-accent']`) or
  `var(--token)`. Never raw hex or px for color and spacing.
- Wrap every `:hover` style in `@media (hover: hover)`.
- Product StyleX is unlayered on purpose (`useCSSLayers: false` in `web/vite.config.ts`) so it
  outranks `reset` / `astryx-base` / `astryx-theme`. Never add other unlayered global CSS, it would
  outrank the design system too. `web/src/styles.css` is the only global stylesheet.
- Theme: `@astryxdesign/theme-neutral/built` via `<Theme>` in `web/src/routes/__root.tsx`, with
  Figtree loaded from `@fontsource/figtree` (static package; the variable one registers a different
  family).
- Routing: TanStack Router, file-based in `web/src/routes`. `<LinkProvider component={Link}>` is
  already wired, so navigate with Astryx `<Link href="/x">` or `<Button href="/x">`, never a raw `<a>`.
- Forms: TanStack Form + zod v4. Astryx inputs are controlled as `(value, onChange(value))`: the
  handler receives the value, not the event.
- Commands (inside `web/`): `pnpm astryx <cmd>`, `pnpm typecheck`, `pnpm lint`, `pnpm check`
  (`pnpm format` to fix).
- The block below is generated by the Astryx CLI, which only writes inside `web/`. To refresh it after
  bumping `@astryxdesign/*`: in `web/`, run `pnpm astryx init --features agents`, copy the block
  between the ASTRYX markers from the generated `web/AGENTS.md` into this file, then delete
  `web/AGENTS.md`.

RULES:
- No <div> — components do all layout/spacing, page frame included.
- Frame first: read `astryx docs layout` before writing any page or screen — page frame, region widths, breakpoint behavior.

- Tokens for every value (`astryx docs tokens`). Brand/accent belongs in the theme (`astryx theme list` / `theme add <slug>`, or `astryx theme template` for a custom one) — never override --color-* in :root.
